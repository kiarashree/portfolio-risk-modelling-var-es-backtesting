
# Financial Market Dataset

## Data Overview

This directory contains the historical financial market data used in the Portfolio Risk Modelling & Analysis group project.

### Data Source
Bloomberg Terminal

### Observation Period
28 March 2022 – 27 March 2026

### Dataset Components
- 30 Dow Jones Industrial Average constituents
- Historical equity prices
- Equity log returns
- Bloomberg Aggregate Bond Index data

### Purpose

The dataset supports:
1. Portfolio construction
2. Return distribution analysis
3. Value at Risk (VaR) estimation
4. Expected Shortfall (ES) estimation
5. Monte Carlo simulation
6. Rolling-window backtesting
7. Sensitivity analysis

### Data Usage

Data is included with permission for the purposes of this academic project and its public presentation.
