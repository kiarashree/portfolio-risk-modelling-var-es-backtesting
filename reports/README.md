
# Portfolio Risk Analysis - Project Report

## Problem

Assess the reliability of alternative risk measurement
models across equity, bond and diversified portfolios.

## Analytical Process

The group evaluated:
- Parametric Value at Risk and Expected Shortfall
- Cornish-Fisher adjustments
- Historical Simulation
- Monte Carlo Simulation
- Exponential Spectral Risk Measures
- Rolling-window VaR and ES backtesting
- Sensitivity analysis at 95% and 99% confidence

## Solution

The analysis supported a portfolio-specific approach
to risk measurement rather than applying one model
uniformly.

## Key Recommendations

- Equity: Historical ES, supported by Cornish-Fisher VaR
- Bonds: Parametric ES
- Combined 60/40: Historical ES
